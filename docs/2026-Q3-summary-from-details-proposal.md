# Q3 总表与分表按单月层级关系保持一致的计算方案

日期：2026-10-27。

本方案按用户后续明确的要求，以分表为准生成总表。它与前一份差异核查说明中“如果继续保留旧累计总表规则”的假设不同。本次只验证方案，未修改业务源代码或现有 Excel。

## 计算顺序

1. 先确定季度分表各一级指标的分数。本次模拟以已生成 Q3 分表的一级分数为起点，不调整它们的跨月计算算法。
2. 按单月精度规则，将这些一级分数统一为两位小数，作为总表、分表共同使用的值。
3. 对每个客群，平均该客群实际存在且有分数的一级指标，得到季度总分，再保留两位小数。缺失项不作 0 分，分母不固定为 4 或 5。
4. 将季度一级指标和重新计算后的总分，同时写入该客群分表与总表对应行。总表不再独立计算同名指标的另一组累计值。
5. 仿照单月总表底部汇总：总体总分取各有效客群总分的平均；各指标列取该列有效客群值的平均。

这样，季度总分从季度一级指标重算，而不直接保留以前从月度总分累计得到的结果。仅把总表指标改成分表数值、却保留旧总分，仍然不能满足用户要求。

## 六类会展客户的餐饮服务规则

以下六类客群，餐饮服务均不是一级指标：

- 展览活动主（承）办
- 参展商
- 专业观众
- 会展服务商
- 会议活动主（承）办
- 参会客户

它是“配套服务”下的子项。总表可以展示其分数，但不单独再次参与这六类客群的总分。上述六类的计算式为：

```text
该客群总分 = 平均（产品服务、硬件设施、配套服务、智慧场馆/服务中有分数的一级指标）
```

其他客群按各自分表的实际一级层级计算。例如，餐饮客群的“餐饮服务”是一级指标，应参与其总分。不能对所有客群机械地平均总表 D:H 五列。

## 会展服务商 Q3 示例

| 指标 | 取自季度分表的分数 | 是否单独参与总分 |
| --- | ---: | --- |
| 产品服务（分表名：会展服务） | 9.92 | 是 |
| 硬件设施 | 9.83 | 是 |
| 配套服务 | 9.80 | 是 |
| 智慧场馆/服务 | 9.84 | 是 |
| 餐饮服务（配套服务子项） | 9.42 | 否 |

```text
季度总分 = (9.92 + 9.83 + 9.80 + 9.84) / 4
         = 9.8475
         = 9.85（保留两位小数）
```

所以这一客群在两张表中都应使用：产品服务 9.92、硬件设施 9.83、配套服务 9.80、智慧场馆 9.84、总分 9.85。餐饮服务仍可展示 9.42。
