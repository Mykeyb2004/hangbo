# 按 TOML 配置填写 Excel 单元格

独立入口为仓库根目录的 `insert_excel_values.py`。它读取现有 Excel 模板，将 TOML 中的值写入指定工作表和单元格，保留模板的常规排版。已有单元格内容会被替换；不插入或移动行、列，也不接入统计和 PPT 主流程。

## 运行

项目要求 Python 3.11 及以上，依赖使用项目现有的 `openpyxl>=3.1.5`，不需要安装 Excel。

1. 准备待填写的 `.xlsx` 或 `.xlsm` 文件。
2. 修改 [示例配置](../configs/excel_insert.toml) 的路径、工作表名、单元格和值。示例中的模板文件名是占位名称，需替换。
3. 在仓库根目录运行：

```bash
uv run python insert_excel_values.py --config configs/excel_insert.toml
```

成功输出 `完成：<输出文件绝对路径>`，退出码为 `0`。配置、读取或保存失败时，标准错误输出 `错误：<原因>`，退出码为 `1`。

## 配置

```toml
[workbook]
input = "../templates/报表模板.xlsx"
output = "../output/填写后报表.xlsx"
overwrite = false
keep_vba = false

[[writes]]
sheet = "汇总"
cell = "B2"
value = "第三季度"

[[writes]]
sheet = "汇总"
cell = "C5"
value = 123.45

[[writes]]
sheet = "明细"
cell = "D8"
value = true
```

| 字段 | 必填 | 含义 |
| --- | --- | --- |
| `workbook.input` | 是 | 现有 Excel 路径，支持 `.xlsx`、`.xlsm` |
| `workbook.output` | 是 | 输出路径，扩展名必须与输入一致；父目录自动创建 |
| `workbook.overwrite` | 否 | 默认 `false`；只有 `true` 才允许替换已有输出文件 |
| `workbook.keep_vba` | 否 | `.xlsx` 默认 `false`，`.xlsm` 默认 `true`；显式设置必须与类型匹配 |
| `writes[].sheet` | 是 | 工作表名称，需与 Excel 中完全一致 |
| `writes[].cell` | 是 | 单个地址，如 `B2`、`$B$2`，字母大小写均可 |
| `writes[].value` | 是 | 要写入的标量值 |

所有相对路径都以 **TOML 文件所在目录** 为基准，与命令的运行目录无关。也支持绝对路径。至少提供一个 `[[writes]]`；同一工作表的同一单元格不可重复指定。未知字段会报错，防止拼写错误被忽略。

如果确实需要原位更新，将 `output` 设置为与 `input` 相同的路径，同时设置 `overwrite = true`。

## 值的类型

| 类型 | TOML 示例 |
| --- | --- |
| 文本 | `value = "第三季度"` |
| 整数、浮点数 | `value = 123` / `value = 123.45` |
| 布尔值 | `value = true` / `value = false` |
| 日期 | `value = 2026-10-09` |
| 本地时间 | `value = 08:30:00` |
| 本地日期时间 | `value = 2026-10-09T08:30:00` |
| 公式 | `value = "=SUM(B2:B8)"` |
| 空白显示 | `value = ""` |

日期和时间不加引号时才会作为日期时间写入。数字格式沿用目标格原格式：写入 `0.95` 到百分比单元格会按原格式显示；日期写入常规或数值格式单元格可能显示为 Excel 日期序列值。因此，需在模板中先设好目标格的日期或百分比格式。

以 `=` 开头的文本按 Excel 公式写入。脚本保留公式表达式，但不计算公式，结果由 Excel 打开后重新计算；openpyxl 保存后也可能清除已有公式的缓存结果。超过 Excel 约 15 位有效数字的编号应配置成文本，例如 `value = "123456789012345678"`，避免 Excel 的数值精度限制。

不支持数组、嵌套表、`nan`、`inf`、带时区的日期时间、非法 XML 控制字符及超过 32767 字符的文本。TOML 没有 `null` 类型；`value = ""` 可用于清空显示内容。

## 格式保留和保存规则

- 保留目标格的字体、填充、边框、对齐、保护属性和数字格式，不自动调整行高、列宽。
- 保留常规行列设置、合并区域、冻结窗格和打印设置，以及其他工作表内容。未修改单元格中的富文本使用 `rich_text=True` 读取和保留。
- 合并区域只允许填写左上角。例如 `D4:E4` 应指定 `D4`，指定 `E4` 会报错。
- 写入前检查所有配置和目标位置；任何条目无效时不保存文件。
- 在输出目录中先保存临时文件，保存完成后再发布。默认通过不覆盖已有文件的方式发布；允许覆盖时使用原子替换。保存或发布失败时清理临时文件，已有源文件和目标文件不会被半成品覆盖。
- `.xlsm` 自动开启宏保留，也可以显式设置 `keep_vba = true`；脚本保留 VBA 文件，不执行宏。测试使用合成 VBA 数据验证保存前后字节一致。

openpyxl 不能保证所有 Excel 高级对象无损保留；复杂形状、控件、数字签名及其他扩展对象可能受影响。普通单元格和排版在测试覆盖范围内，包含复杂对象的模板应检查另存结果后再用于正式交付。旧版 `.xls`、`.xlsb`、加密工作簿不受支持。

## 验证

```bash
uv run python -m unittest discover -s tests -p test_insert_excel_values.py -v
```

测试在临时目录生成工作簿，覆盖命令行读写、源文件保护、样式和布局、多工作表、多种数值类型、日期格式、合并区域、配置错误、宏保留及保存失败保护，不修改仓库中的业务 Excel。
